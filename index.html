Theme 1 · Politics & Elections

What is reported: Preparations for the Negeri Sembilan state election are intensifying. Barisan Nasional named 25 candidates and left 11 seats open — a possible pact with Perikatan Nasional (PN) and PAS. But PN is split: Bersatu says it will contest under its own logo and won't back down from PAS if talks fail. Why it matters: State-level instability can translate into policy uncertainty and slower decisions for business. For Singapore companies with interests in Negeri Sembilan or Malacca, shifting state governance could change regulatory conditions and development plans — fluidity that investors typically treat with caution.

Under the hood

Built from simple, free parts.

No fancy infrastructure — just a few free tools wired together.

A free daily run on GitHub

GitHub Actions — a free scheduling service from GitHub — automatically starts the tool once a day. No need to rent a server or keep a laptop running 24/7 just to trigger the daily task.

🐍

A short Python script

A small program written in Python (a popular, beginner-friendly programming language) fetches the day's news from the news sites and sends out the finished email. It handles all the plumbing.

🤖

A free Gemini AI model

Google's Gemini AI reads the headlines and writes the summary, picking out what matters for Singapore businesses. It runs on Google's free tier, so it costs nothing.
